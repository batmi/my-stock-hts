# 이 파일이 '무엇을 설치해야 프로그램이 도는가'의 유일한 정의다.
#  run.sh 가 기동 시 이 파일을 읽어 미설치 라이브러리를 스캔·설치하므로,
#  의존성을 추가할 때는 여기만 고치면 된다(run.sh 의 목록을 따로 고치지 않는다).
#  단, PyPI 배포명과 import 이름이 다른 패키지는 run.sh 의 `_import_name()` 표에
#  한 줄을 함께 추가해야 스캔이 올바로 동작한다.
#
# [작성 기준] 2026-08-23 전수 재작성. 코드베이스의 모든 import 문을 AST 로 훑어
#  실제로 참조되는 서드파티만 남겼다. 종전 파일은 pipreqs 류의 출력이 그대로 남아
#  있어 실제 의존성(rich·pandas·yfinance·requests·pykrx ...)이 전부 빠지고,
#  코드에서 한 번도 import 하지 않는 것들(PyQt6·PySide6·pyspark·selenium·Flask ...)이
#  들어 있었다 — 라즈베리파이에서 이 파일로 설치하면 쓰지도 않는 GUI 툴킷을
#  빌드하려다 시간과 SD 수명을 태우고 실패한다.
#
# [버전 정책] 상한은 두지 않고 하한만 둔다. 운영기(라즈베리파이3)에서 재설치가
#  강제 업그레이드로 이어지지 않게 하되, 코드가 요구하는 API 가 없는 구버전은 막는다.
#  개발기에서 실제로 검증된 조합은 파일 끝의 '검증 조합' 주석을 참조.
#
# [테스트 의존성] pytest 계열은 requirements-dev.txt 로 분리했다. 기동 경로가
#  테스트 도구 설치를 기다릴 이유가 없다.  →  pip install -r requirements-dev.txt
# ============================================================================
