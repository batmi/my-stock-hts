# 📈 MyStock HTS (Home Trading System)

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

안녕하세요! **MyStock HTS**는 한국투자증권(KIS) Open API를 활용하여 파이썬으로 개발된 **개인용 주식 자동매매 및 분석 시스템**입니다. 🚀
터미널(Console) 환경에서 가볍고 빠르게 동작하며, 실시간 시세 조회부터 정밀한 기술적 분석, 그리고 나만의 전략을 기반으로 한 자동매매 기능까지 올인원으로 제공합니다.

1. **투자 결과에 대한 책임**: 본 소프트웨어는 개발 및 학습 목적으로 작성되었으며, 투자의 보조 수단일 뿐입니다. 본 소프트웨어를 사용하여 발생한 모든 투자 손실 및 피해에 대한 책임은 전적으로 **사용자 본인**에게 있으며, 개발자는 이에 대해 어떠한 법적, 금전적 책임도 지지 않습니다.

3. **검증 권장**: 실전 투자에 앞서 반드시 **모의투자** 환경에서 충분한 기간 동안 시스템의 안정성과 전략의 유효성을 검증하시기 바랍니다.

## 1. 🌟 프로그램 개요 및 특징

이 프로그램은 **기술적 분석을 중시하는 퀀트(Quant) 및 시스템 트레이더**를 위해 설계된 CLI 기반의 강력한 도구입니다. 무거운 HTS(홈 트레이딩 시스템) 없이 터미널에서 빠르고 직관적으로 시장을 분석하고 매매할 수 있습니다.

### ✨ 주요 특징
* **🖥️ 초경량 터미널 HTS**: 실시간 시세 조회 및 매수/매도/정정/취소 주문 실행
* **🤖 기술적 분석 및 자동화**: EMA 정배열, RSI, MACD 등 보조지표를 종합하여 직관적인 투자 판단 신호(매수/상승/관망/주의/매도) 제공
* **⚙️ 개별 종목 맞춤 전략**: 종목마다 다른 매수/매도 기준(점수, RSI)과 익절/손절/트레일링 스탑 비율 설정 가능
* **🛡️ 리스크 관리**: KOSPI/KOSDAQ 지수 추세를 분석하여 하락장에서는 자동으로 신규 매수 보류
* **⏱️ 실시간 설정 반영**: 트레이딩 실행 중에도 매수/매도 조건 및 투자 비중을 즉시 변경 (재시작 시에도 유지)
* **🌎 통합 관리**: 한국투자증권 API를 통해 국내/미국 주식을 하나의 인터페이스에서 관리
* **🎮 실전/모의 투자 완벽 지원**: 간단한 설정 변경으로 모의 투자와 실전 투자를 자유롭게 넘나들 수 있음
* **🔬 전략 백테스팅**: 과거 데이터를 바탕으로 내 매매 전략의 수익률을 시뮬레이션 및 검증

## 2. ✅ 필수 준비 사항

본 프로그램은 **한국투자증권(Korea Investment & Securities)**의 Open API를 사용합니다. 따라서 한국투자증권 계좌와 API 접근 키(App Key / App Secret)가 필요합니다.

1. **계좌 개설**: 스마트폰 앱('한국투자증권')을 통해 비대면 계좌 개설
2. **KIS Developers 가입 및 신청**: [KIS Developers 포털](https://apiportal.koreainvestment.com/) 접속 후 API 서비스 신청
3. **모의투자 신청 (강력 권장!)**: 홈페이지나 HTS에서 상시 모의투자 신청 (테스트 및 연습용)
4. **API Key 발급**: 마이페이지 > 내 서비스 > 발급받기 (실전용과 모의투자용 각각 발급 가능)
5. **정보 준비**: 발급받은 `App Key`, `App Secret` 그리고 `계좌번호`를 메모해 둡니다.

## 3. 🚀 설치 및 실행 방법

### 환경 설정
* **Python 3.9 이상** 설치 필요

### 소스 코드 다운로드 및 설치
1. 프로젝트를 다운로드(Clone) 받은 후, 터미널(또는 명령 프롬프트)에서 해당 폴더로 이동합니다.
2. 운영체제에 맞는 실행 스크립트를 실행하면 **필요한 라이브러리를 자동으로 확인하고 설치해 줍니다!**

#### 🍎 macOS / 🐧 Linux 환경
```bash
# 최초 1회 실행 권한 부여
chmod +x run.sh

# 프로그램 실행
./run.sh

# (옵션) 도움말 보기
./run.sh --help

# (옵션) 모의투자로 자동매매 바로 시작하기
./run.sh --mode 1 --auto
```

#### 🪟 Windows 환경
```cmd
# 프로그램 실행
run.bat

# (옵션) 도움말 보기
run.bat --help

# (옵션) 실전투자 모드로 텔레그램 봇 수신 없이 바로 시작하기
run.bat --mode 2 --no-bot
```

### 기본 설정 (환경 변수 또는 `config.py`)
발급받은 API 키 정보를 `config.py` 파일에 직접 입력하거나, 보안을 위해 시스템 환경 변수로 등록하는 것을 권장합니다.
* `SIM_APP_KEY`, `SIM_APP_SECRET`: 모의투자용 API Key
* `REAL_APP_KEY`, `REAL_APP_SECRET`: 실전투자용 API Key
* `SIM_ACC_NUM`, `REAL_ACC_NUM`: 계좌번호 (예: 12345678-01)

## 4. 🧭 주요 메뉴 안내

프로그램을 실행하면 직관적인 번호 선택 메뉴가 나타납니다.

* **[0] 시스템 설정**: 프로그램 실행 중에도 동적으로 매수/매도 점수 기준, 리스크 관리 비율, 텔레그램 설정 등을 변경할 수 있습니다.
* **[1] 시장 지수 조회**: 국내/해외 주요 시장 지수, 원자재, 환율 등 거시 경제 지표를 한눈에 파악합니다.
* **[2] 종목 시세 분석**: 현재 관심 종목들의 상태(점수, 기술적 지표, 시그널)를 분석하여 색상과 함께 보여줍니다.
* **[3] 종목 차트 분석**: 특정 종목이나 지수의 최근 흐름을 파라볼릭 SAR, MACD, RSI, ADX 지표와 함께 시각화된 차트로 확인합니다.
* **[4] 관심 종목 관리**: 매매를 원하거나 지켜보고 싶은 종목(국내/미국 주식, ETF)을 추가하고 관리합니다.
* **[5] 시스템 트레이딩**: **(핵심 기능!)** 설정된 전략에 따라 백그라운드에서 실시간으로 시장을 감시하며 자동으로 매수/매도/익절/손절을 수행합니다.
* **[6] 전략 백테스팅**: 과거 데이터를 기반으로 현재 설정된 전략의 예상 수익률, MDD(최대 낙폭), 승률 등을 테스트합니다.
* **[7] 매수/매도 주문 & [8] 정정/취소 주문**: HTS처럼 직접 수동으로 매매 주문을 넣거나 취소/정정합니다.
* **[9] 자산 관리**: 현재 계좌의 예수금, 보유 종목 목록, 실시간 손익 현황을 조회합니다.

## 5. 📱 텔레그램 알림 및 제어

매매 내역을 스마트폰으로 실시간 알림 받고, 원격으로 봇을 제어하려면 텔레그램 연동을 강력 추천합니다!

1. 텔레그램에서 **@BotFather**를 검색하여 대화를 시작합니다.
2. `/newbot` 명령어로 새로운 봇을 만들고 **API Token**을 발급받습니다.
3. 생성한 봇에게 아무 메시지나 먼저 보냅니다 (예: "Hello").
4. 이 프로그램 폴더에 있는 `get_telegram_chat_id.py`를 실행하고 발급받은 토큰을 입력하면 **Chat ID**를 확인할 수 있습니다.
5. 확인한 토큰과 Chat ID를 `config.py`의 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`에 입력합니다.

**💬 텔레그램 봇 주요 명령어 예시**
* `/status`: 시스템 구동 상태 확인
* `/balance`: 현재 계좌 잔고 확인
* `/holdings`: 보유 종목 현황 확인
* `/start` / `/stop`: 시스템 트레이딩 원격 시작/중단
* `/signal <종목명>`: 특정 종목의 현재 진단 결과 확인

## 6. 📊 매매 전략 (Scoring System)

본 시스템은 **추세 추종(Trend Following)** 전략과 여러 보조지표를 결합한 **퀀트 멀티팩터 모델**을 사용합니다. 총점은 10점 만점입니다.

### 🟢 매수 전략 (10점 만점 중 기본 8.0점 이상)
* **추세 (Trend) [+4.0점]**: 이동평균선 정배열, MACD 골든크로스, 파라볼릭 SAR 상승 추세
* **모멘텀 (Momentum) [+2.5점]**: RSI 강세 구간(50~75), CCI 상승
* **강도/수급 (Strength) [+1.5점]**: ADX 추세 형성(20 이상), OBV 수급 양호
* **시너지 (Synergy) [+2.0점]**: 지표들이 완벽하게 동조화될 때 주어지는 가산점

> **판단 가이드**
> * **8.5 ~ 10.0점**: 강력 매수 구간! 모든 지표가 완벽하게 상승을 가리킵니다.
> * **7.0 ~ 8.0점**: 매수 구간. 확실한 추세가 보입니다. 분할 매수하기 좋은 시점입니다.
> * **5.5 ~ 6.5점**: 관망. 상승 초입이거나 힘이 빠지는 중입니다. 조금 더 지켜보세요.
> * **5.0점 미만**: 매도/진입 금지. 뚜렷한 추세가 없거나 하락 중입니다.

### 🔴 매도 전략 (철저한 리스크 관리)
* **익절 (Take Profit)**: 설정한 수익률(예: +30%) 도달 시 즉시 매도
* **손절 (Stop Loss)**: 설정한 손실률(예: -7%) 도달 시 즉시 매도 (ATR 기반 동적 손절 지원)
* **트레일링 스탑**: 목표 수익(예: +10%) 도달 후 고점 대비 일정 비율(예: -3%) 하락 시 수익을 지키며 매도
* **과열 매도**: RSI가 75를 초과하면 곧 조정을 받을 수 있다고 판단하여 미리 익절
* **추세 이탈**: 종합 점수가 5.0점 미만으로 꺾이거나 중요 지지선(60일/120일)이 무너지면 전량 매도

## 7. ⚙️ 상세 설정 가이드

대부분의 세부 설정은 `config.py` 파일 또는 프로그램 내 **[0] 시스템 설정** 메뉴에서 조정할 수 있습니다.

| 설정 항목 | 설명 | 기본값 |
|---|---|---|
| `BUY_SCORE` | 진입을 결정하는 종합 매수 점수 하한선 | 8.0점 |
| `TAKE_PROFIT_RATE` | 기본 익절 수익률 (%) | +30.0% |
| `STOP_LOSS_RATE` | 기본 손절 손실률 (%) | -7.0% |
| `SYSTEM_INVEST_PER_STOCK`| 한 종목에 투자할 최대 자산 비중 (0.5 = 50%) | 0.5 |
| `SYSTEM_MAX_HOLDINGS` | 최대 보유 가능한 종목 개수 | 5개 |
| `USE_MARKET_FILTER` | 하락장 판단 시 자동 매수 보류 기능 사용 여부 | True |
| `USE_VOLATILITY_TARGETING`| 시장 변동성에 따라 자동으로 투자 비중을 조절하는 기능 | True |

## 8. 💡 자주 묻는 질문 (FAQ)

**Q. API 토큰 만료 오류가 자꾸 발생합니다.**
> 한국투자증권 API 토큰은 매일 발급받아야 합니다. 프로그램이 실행 중일 때는 자동으로 갱신(`TOKEN_EXPIRED` 처리)되지만, 수동으로 갱신하고 싶다면 프로그램을 껐다가 다시 실행해 주세요.

**Q. 종목 코드를 입력했는데 조회가 되지 않아요.**
> 해외 주식(미국)의 경우 티커 심볼(예: AAPL, TSLA)을 대문자로 정확히 입력해 주세요. 그래도 안 된다면 해당 종목이 한국투자증권 API에서 지원하지 않거나 코드가 변경되었을 수 있습니다.

**Q. `ModuleNotFoundError: No module named 'rich'` 오류가 떠요.**
> 파이썬 라이브러리가 제대로 설치되지 않은 상태입니다. 터미널(또는 CMD)에서 `pip install -r requirements.txt` 또는 `pip install rich yfinance pandas matplotlib openpyxl requests` 명령어를 직접 입력하여 설치해 보세요. (macOS/Linux의 경우 `pip3`를 사용해야 할 수도 있습니다.)

**Q. 모의투자와 실전투자 계좌를 동시에 사용할 수 있나요?**
> 동시에 실행할 수는 없지만, 터미널 창을 2개 띄워서 각각 다른 모드(`--mode 1` 과 `--mode 2`)로 실행하는 것은 가능합니다.

## 9. 📁 프로젝트 구조

```text
my-stock-hts/
├── run.sh              # [Mac/Linux] 원클릭 실행 스크립트
├── run.bat             # [Windows] 원클릭 실행 스크립트
├── config.py           # 시스템/전략 설정, 환경변수 관리
├── api.py              # KIS API 통신 및 데이터 조회 처리
├── constants.py        # API 통신용 상수 정의 (TR ID 등)
```
