# MyStock HTS (Home Trading System)

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

한국투자증권(KIS) Open API를 활용한 파이썬 기반의 개인용 주식 자동매매 및 분석 시스템입니다.
터미널(Console) 환경에서 동작하며, 실시간 시세 조회, 정밀한 기술적 분석, 그리고 전략 기반의 자동매매 기능을 제공합니다.

## 1. 프로그램 개요 및 목적
이 프로그램은 **기술적 분석을 중시하는 퀀트(Quant) 및 시스템 트레이더**를 위해 설계된 CLI(Command Line Interface) 기반의 올인원 주식 도구입니다.
무거운 HTS(홈 트레이딩 시스템) 없이도 터미널 환경에서 빠르고 직관적으로 시세 조회, 잔고 확인, 주문 실행을 수행할 수 있으며, 감에 의존하기보다 **데이터와 지표(EMA 정배열, RSI, MACD 등)**에 근거하여 매매 타이밍을 잡을 수 있도록 돕습니다.

### 주요 특징
*   **HTS/MTS 대체:** 터미널에서 실시간 시세 조회 및 매수/매도/정정/취소 주문 실행
*   **기술적 분석 자동화:** 복잡한 보조지표 계산을 자동화하여 **'매수/관망/주의/위험'** 등의 직관적인 투자 판단 신호 제공
*   **개별 종목 전략 설정:** 종목별로 다른 매수/매도 기준(점수, RSI)과 익절/손절/트레일링 스탑 비율을 개별적으로 설정 가능
*   **시장 지수 필터링:** KOSPI/KOSDAQ 지수의 추세를 분석하여 하락장에서는 자동으로 매수를 보류하는 리스크 관리 기능
*   **실시간 설정 변경:** 시스템 트레이딩 실행 중 매수/매도 조건 및 투자 비중을 즉시 변경하고 영구 반영하는 기능
*   **국내/해외 통합 관리:** 한국투자증권(KIS) API를 활용하여 국내 주식과 미국 주식을 하나의 인터페이스에서 통합 관리
*   **실전/모의 투자 지원:** 설정 변경만으로 모의 투자와 실전 투자를 손쉽게 전환
*   **전략 백테스팅:** 과거 데이터를 기반으로 현재의 매매 전략을 검증하고 수익률을 시뮬레이션

## 2. 필수 준비 사항 (Prerequisites)
이 프로그램은 **한국투자증권(Korea Investment & Securities)**의 Open API를 기반으로 동작합니다.
따라서 프로그램을 정상적으로 실행하기 위해서는 반드시 한국투자증권의 계좌와 API 접근 키가 필요합니다.

### 준비 절차 (Step-by-Step)
1.  **한국투자증권 계좌 개설**: 스마트폰 앱('한국투자증권') 등을 통해 비대면 계좌 개설
2.  **KIS Developers 서비스 신청**: [한국투자증권 KIS Developers](https://apiportal.koreainvestment.com/) 접속 및 서비스 신청
3.  **모의투자 신청 (권장)**: 홈페이지/HTS에서 상시 모의투자 신청 (테스트용)
4.  **API Key 발급**: 마이페이지 > 내 서비스 > 발급받기 (실전/모의 각각 발급 가능)
5.  **환경 변수 등록**: 발급받은 Key와 계좌번호를 시스템 환경 변수로 등록 (아래 설치 방법 참고)

## 3. 설치 및 설정

### 1. 환경 설정
*   Python 3.9 이상

### 2. 라이브러리 설치
**[권장]** `run.sh` (macOS/Linux) 또는 `run.bat` (Windows) 스크립트를 실행하면 필요한 라이브러리를 확인하고 **자동으로 설치를 안내**합니다.

수동으로 설치하려면 아래 명령어를 사용하세요.
```bash
pip install requests pandas yfinance rich matplotlib numpy openpyxl
```

### 3. 설정 (Configuration)
보안을 위해 API Key 등 민감 정보는 **환경 변수**로 설정하는 것을 권장합니다.

**주요 환경 변수:**
*   `SIM_APP_KEY`, `SIM_APP_SECRET`: 모의투자 API Key
*   `REAL_APP_KEY`, `REAL_APP_SECRET`: 실전투자 API Key
*   `AUTO_APP_KEY`, `AUTO_APP_SECRET`: (선택) 자동매매 전용 계좌 API Key (실전투자 시 분리 운용 가능)
*   `SIM_ACC_NUM`: 모의투자 계좌번호 (예: 12345678-01)
*   `REAL_ACC_NUM`: 실전투자 계좌번호
*   `AUTO_ACC_NUM`: (선택) 자동매매 전용 계좌번호
*   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: 텔레그램 알림 설정

*또는 `config.py` 파일을 직접 수정하여 기본 설정을 변경할 수 있습니다.*

### 4. 실행
```bash
# 실행 권한 부여 (최초 1회)
chmod +x run.sh

# 메인 프로그램 실행 (대화형 메뉴)
./run.sh

# 도움말 및 옵션 확인
./run.sh --help

# 자동매매 모드로 바로 시작 (예: 모의투자)
./run.sh --mode 1 --auto
```

## 📱 텔레그램 알림 및 제어 설정 (Telegram Bot)

시스템 트레이딩의 매매 내역 알림을 받고 원격으로 제어하기 위해 텔레그램 봇 연동을 권장합니다.

### 1. 봇 생성 (BotFather)
1. 텔레그램에서 **@BotFather** 검색 후 대화 시작.
2. `/newbot` 입력 후 안내에 따라 봇 이름과 ID 설정.
3. 발급된 **API Token** 복사.

### 2. Chat ID 확인
1. 생성한 봇에게 아무 메시지나 전송 (예: "start").
2. 프로젝트 폴더의 `get_telegram_chat_id.py` 실행:
   ```bash
   python get_telegram_chat_id.py
   ```
3. 토큰을 입력하면 **Chat ID**가 출력됩니다.

### 3. 환경 변수 등록
`config.py` 또는 시스템 환경 변수에 설정합니다.
*   `TELEGRAM_BOT_TOKEN`: API Token
*   `TELEGRAM_CHAT_ID`: Chat ID

### 4. 주요 명령어
*   **상태 및 자산**: `/status` (상태), `/balance` (잔고), `/holdings` (보유종목), `/profit [d/w/m]` (기간별 손익)
*   **제어**: `/start` (시작), `/stop` (중단), `/restart` (재시작)
*   **분석**: `/market` (시장지수), `/signal <종목>` (종목진단), `/chart <종목>` (차트전송)
*   **정보**: `/report` (성과리포트), `/history [건수]` (체결내역), `/log [줄수]` (시스템로그)
*   **설정**: `/config` (전략설정), `/rules [종목]` (개별룰), `/stocks` (감시종목)


## 📊 매매 전략 개요

본 시스템은 추세 추종(Trend Following) 전략을 기본으로 합니다.

*   **매수**: 이동평균선 정배열, SAR 상승 추세, RSI 적정 구간(40~55), ADX 추세 강도 등을 종합하여 점수화(Score)하고, 기준 점수 이상일 때 진입합니다.
*   **매도**:
    1.  **익절/손절**: 설정된 수익률 도달 시
    2.  **트레일링 스탑**: 고점 대비 일정 비율 하락 시
    3.  **추세 이탈**: 종합 점수 하락 또는 주요 지지선(60일선 등) 붕괴 시
    4.  **과열**: RSI가 과매수 구간(70 이상)에 진입 후 꺾일 때

## ⚙️ 전략 파라미터 상세 (Configuration)

`config.py` 파일에서 **기본 전략(Global Strategy)**을 설정할 수 있으며, 프로그램 내 **'시스템 트레이딩 > 종목별 트레이딩 룰'** 메뉴를 통해 종목별로 개별 설정을 적용할 수 있습니다.
또한, **'메인 메뉴 > [0] 시스템 설정'** 메뉴를 통해 실행 중에도 전역 설정을 실시간으로 수정할 수 있습니다. (재시작 시에도 유지됨)

### 1. 기술적 지표 설정 (`INDICATOR_PARAMS`)
*   **데이터 조회 기간 (`CHART_LOOKBACK_DAYS`)**: 730일 (2년). 이동평균선(120일선 등)의 정확한 계산을 위해 충분한 과거 데이터를 조회합니다.
*   **RSI (상대강도지수)**:
    *   기간: 14일 (`RSI_PERIOD`)
    *   과매수 기준: 70 (`RSI_UPPER`) / 과매도 기준: 30 (`RSI_LOWER`)
*   **Parabolic SAR (추세 반전)**:
    *   가속변수(AF): 시작 0.02 (`SAR_AF_START`), 증가 0.02 (`SAR_AF_STEP`), 최대 0.2 (`SAR_AF_MAX`)
    *   값을 키우면 추세 반전 신호가 빨라지지만 속임수 신호가 늘어날 수 있습니다.
*   **CCI (상품채널지수)**:
    *   기간: 20일 (`CCI_WINDOW`)
    *   과매수/과매도 기준: ±100 (`CCI_UPPER`, `CCI_LOWER`)
*   **ADX (추세 강도)**: 기간 14일 (`ADX_PERIOD`). 25 이상일 때 강한 추세로 간주합니다.

### 2. 매수/분석 임계값 (`ANALYSIS_THRESHOLDS`)
*   **매수 기준 점수 (`BUY_SCORE`)**: 기본값 **8점**. 여러 기술적 지표(이평선, SAR, RSI, ADX 등)를 종합한 점수가 이 값 이상일 때 매수 신호가 발생합니다.
*   **상승 추세 점수 (`RISE_SCORE`)**: 기본값 **6점**. 매수 기준에는 미치지 못하지만 상승 흐름이 있는 상태입니다.
*   **매수 허용 RSI 상한 (`BUY_RSI_MAX`)**: 기본값 **60**. 매수 점수를 충족하더라도, RSI가 이 값 이상이면 이미 과열된 것으로 보고 진입하지 않습니다.
*   **매수 체결강도 기준 (`BUY_VOL_STRENGTH`)**: 기본값 **100.0%**. 매수 시점의 체결강도가 이 값 이상이어야 진입합니다. (매수세 우위 확인)

### 3. 매도 전략 (`SELL_STRATEGY`)
*   **익절 (Take Profit)**: 수익률 **+30.0%** (`TAKE_PROFIT_RATE`) 도달 시 이익 실현.
*   **손절 (Stop Loss)**: 손실률 **-7.0%** (`STOP_LOSS_RATE`) 도달 시 손실 확정.
*   **트레일링 스탑 (Trailing Stop)**:
    *   **발동 조건**: 수익률 **+10.0%** (`TRAILING_STOP_ACTIVATION_RATE`) 도달 시 감시 시작.
    *   **매도 조건**: 최고가 대비 **-3.0%** (`TRAILING_STOP_CALLBACK_RATE`) 하락 시 매도.
*   **과열 매도**: RSI가 **75** (`TAKE_PROFIT_RSI`)를 초과하면 과매수 구간으로 판단하여 선제적 매도.
*   **추세 이탈 매도**: 종합 점수가 **5점** (`SELL_SCORE`) 미만으로 떨어지면 매도.

### 4. 리스크 관리 및 필터링
*   **시장 지수 필터링**: KOSPI/KOSDAQ 지수가 이동평균선(기본 20일) 아래로 하락하면 '하락장'으로 간주하여 신규 매수를 자동으로 보류합니다.
*   **일일 손실 제한**: 당일 추정 자산이 설정된 손실 한도(예: -3%)를 초과하여 하락하면 시스템을 비상 정지합니다.
*   **최대 보유 종목 수**: 자산 비중 설정에 따라 최대 보유 가능한 종목 수를 제한합니다.

    ├── trading.py      # [7,8] 주문 관리
    └── account.py      # [9] 자산 관리
